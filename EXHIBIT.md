# About

**Polycule Molecule** is a multiplayer relational building game where you
court potential lovers using limited resources and form bonds with others.
A top-down social simulation for four players exploring polyamorous
relational dynamics through movement, proximity, and the five love
languages. Players share a single screen while each using their own phone as
a controller, courting persona nodes that drift through a shared arena.
Over each round, bonds form, decay, and branch into emergent network shapes.
